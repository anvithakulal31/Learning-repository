# Git and Full Stack Development – Learning Notes

## 1. Introduction to Git

Git is a version control system used to track changes in files and manage different versions of projects.

### Key Concepts

* Repository: Stores project files and their version history.
* `git init`: Initializes a Git repository.
* `git add`: Stages changes for a commit.
* `git commit`: Records changes in the repository.
* `git status`: Shows the current status of files.
* `git log`: Displays the commit history.

### What I Learned

* Understanding the basics of Git.
* Learning about repositories and commits.
* Understanding how Git tracks changes in files.
* Exploring basic Git commands.

## 2. Introduction to Full Stack Development

Full stack development involves building both the frontend and backend of a web application.

### Frontend Development

The frontend is the part of a website that users interact with.

* HTML: Defines webpage structure.
* CSS: Styles webpages.
* JavaScript: Adds interactive functionality.

### Backend Development

The backend handles server-side logic and processes requests from the frontend.

* Handles application logic.
* Processes user requests.
* Communicates with databases.
* Connects frontend and backend through APIs.

### Database

A database stores and organizes application data.

Examples: MySQL, MongoDB, and PostgreSQL.

## 3. How Full Stack Development Works

1. The user interacts with the frontend.
2. The frontend sends a request to the backend.
3. The backend processes the request.
4. The backend communicates with the database when needed.
5. The response is returned to the frontend.

## 4. Key Takeaways

* Learned the fundamentals of Git.
* Understood repositories, commits, and basic Git commands.
* Explored frontend and backend development.
* Understood the basic roles of APIs and databases.
* Learned how frontend and backend components work together.
